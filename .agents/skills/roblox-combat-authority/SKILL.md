# Roblox Combat Authority

Treat every client payload and timestamp as hostile.
Keep ammo, cadence, hit acceptance, damage, health, rewards and progression authoritative on the server.
Validate payload type, bounds, player state, ownership, origin, direction, rate and sequence.
Allow client prediction only for presentation and reconcile to accepted server results.
Reject continuous aim remotes unless measured gameplay requirements justify them.
Require deterministic acceptance and rejection tests before expanding beyond the first AR path.
