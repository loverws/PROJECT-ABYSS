# PROJECT ABYSS — RIVALS Benchmark Director Review
Date: 2026-09-09
Status: DIRECTOR REVIEW COMPLETE

## Accepted findings
- RIVALS combat tempo cannot be represented by WalkSpeed alone.
- Sprint -> slide -> jump / slide-cancel is a foundational tempo mechanic in RIVALS.
- Strafe/evasion, air control, equipment mobility, map traversal, TTK, and mobile execution burden must be evaluated jointly.
- Exact numeric RIVALS movement values are not established by current evidence and must not be fabricated.
- ABYSS should keep one normalized base Movement Core across PvE and Competitive; PvE build mobility is an explicit modifier layer.

## Rejected / corrected local-model claims
- Do NOT assume ABYSS must reproduce RIVALS slide-jump tempo. RIVALS is a reference index, not a cloning target.
- Multi-jump / explosive / utility mobility is not approved as ABYSS base movement.
- Any unsupported exact speed, jump, TTK, or traversal number remains BLOCKED.

## Gate 1 consequence
Gate 1 remains open only for combat-tempo calibration. Production gameplay source stays LOCKED.
The next design artifact is an ABYSS candidate-profile matrix around RIVALS=100 using relative indices, not fake physical measurements.
