# Real Phone Human Gate

## Checks for real phone compliance:
- Orientation (landscape/portrait support)
- Reachability (UI elements within thumb zone)
- Simultaneous move/look/fire operations
- Readability (text size, contrast)
- Provisional sensitivity settings
- Aim assistance without locking targets
- Frame time consistency
- Memory usage efficiency
- Recording capability compatibility

Only the owner/human can mark PASS.
